## Intended concept

A single-file 3D cyberpunk endless flyer: procedurally generated corridor
geometry and neon lighting, no external art assets, rendered with Three.js from a
CDN so the whole thing stays one HTML file.

## The duplication, and how it should be resolved

This repository and `umutseve4/neon-overdrive` were created with the same two
files and the same README text — they are duplicates, not two projects. Keeping
both public makes the portfolio look padded.

**Recommended resolution:** keep **`neon-overdrive`** (the shorter, more natural
name) as the eventual home of the implementation and delete this one. Repository
deletion requires the owner and cannot be done with an automation token.

## Why the README says this instead of pitching the game

A public README that describes a game in the present tense while shipping zero
lines of that game misrepresents the work. Every repository on this account is
held to one rule: **the README describes only what the committed code actually
does.**
