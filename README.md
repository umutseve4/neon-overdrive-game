## Intended concept

A single-file 3D cyberpunk endless flyer: procedurally generated
corridor geometry and neon lighting, no external art assets, rendered
with Three.js from a CDN so the whole thing stays one HTML file.

## Duplicate of `neon-overdrive`

This repository and `umutseve4/neon-overdrive` were created with the
same two files and the same README text - they are duplicates of each
other, not two different projects. Keeping both public makes the
portfolio look padded.

Recommended resolution: keep **`neon-overdrive`** (the shorter, more
natural name) as the eventual home of the implementation and delete
this one. Repository deletion requires the owner and cannot be done
with an automation token.

## Why the README says this instead of pitching the game

A public README that describes a game in the present tense while
shipping zero lines of that game misrepresents the work. Every other
repository in this account is held to the rule that the README describes
only what the committed code actually does.
