## Why this repository still exists

Repository deletion requires the account owner acting through the GitHub web
interface; it cannot be performed with an automation token. Until then this page
exists so that anyone who lands here from a search result is sent to the real
code in one click instead of reading a pitch for software that is not present.

**Recommended resolution:** delete this repository. Nothing in it is unique.

## The rule this page is following

A public README that describes a game in the present tense while shipping zero
lines of that game misrepresents the work. Every repository on this account is
held to one rule: **the README describes only what the committed code actually
does.** An empty repository is allowed to say so.
